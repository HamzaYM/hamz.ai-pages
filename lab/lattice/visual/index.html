Chapter 01 · The freeze

Seventeen tasks, locked before anything ran

Seventeen real tasks, each with a pass checklist, frozen and hash-stamped before a single run. Seventeen skills, one task each. The full slate:

  • sign off a clinic scheduler's appointment-search PR
  • review the payment integration before refunds work
  • trace cross-clinic data leaks in appointment lists
  • plan parallel engineers through a findings backlog
  • open a PR for a branch built on in-progress work
  • find why nightly classifier accuracy fell to zero
  • audit an LLM document pipeline before switch-on
  • plan an overnight re-score of a full transcript set
  • vet a new patient-reminder toggle and its config
  • audit a reply grader's composite scores and rankings
  • scope moving a FastAPI container to serverless edge
  • debug tenant bleed and a broken local database rebuild
  • check a copied-from-staging production setup before launch
  • review patient-data batch jobs before they go live
  • fact-check a release note against the repository
  • vet a postmortem draft before customers see it
  • judge a plan to refresh goldens so tests pass
