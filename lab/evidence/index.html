The lab / the skills study

Do Claude Code skills change agent behavior?

A skill is a written playbook an agent loads before it works. The question was whether loading one changes what the agent actually does. I did not want an opinion about that, so I measured it.

Read the lattice first

One judge that was never told which output came from which run (order-blinded judge) graded each pair once. The effort lattice re-ran this question but added repeated runs, two blinded judges (with a third settling disagreements), and a second vendor re-scoring a sample of the calls. This time, it was on the 17-skill released library exactly as shipped. I would recommend prioritizing your read on that study, but I will keep this page up for transparency as it is where the released skills came from.

01The design

The design

I made these skills myself, with Claude helping: it went through what I keep asking my agents to do across two production codebases, helped me consolidate those repeated asks into 26 candidate skills, and has helped me refine them since. I selected eight for an order-blinded A/B across 50 pre-registered must-hits in 16 tasks: eight skills, two tasks each.

A must-hit is a pass/fail expectation written in advance. The output either meets it or it does not, and each task carried its own short list, 50 across the suite.

Two words in that design carry the weight. Pre-registered means the pass rule and every expectation were written down before any skill file existed, so the test could not drift toward the result I wanted. Order-blinded means judges saw the two reports for a task in an alternating order and were not told which arm was which.

Every task ran twice. In the cold arm, an agent worked the task with no skill loaded. In the loaded arm, an agent worked the same task with the skill loaded. A judge then graded each pair against the task's must-hits.

The harness this ran on is stage 03 of the assurance chain, the standard the client work passes. That page describes the instrument. This page is what happened when I pointed it at my own tools.

02The numbers

The numbers

Fifty must-hits, graded in both arms.

baseline, no skills
26 / 50
with the tested skills
46 / 50

Task must-hits rose from 26/50 to 46/50, and all 8 tested skills cleared the pre-registered rule. The lineage, in one line: 8 repository-specific skills tested, 17 generalized skills released, 5 of the 17 carrying individual A/B lineage. The library ships as Reliable AI Skills, open source, with the harness included so you can grade your own.

The rule itself was fixed in the plan before the first run: a skill passes only if its loaded runs beat its cold runs and clear at least two thirds of their must-hits. Four tasks tied between arms; the gains came from the rest.

04What this does not show

What this does not show

This study has its limits and for the sake of transparency, I am stating them plainly. That way, you don't need to go looking for them yourself and the results stay clearly bounded.

The stated limit

The judging was order-blinded, not content-blinded. The order key was withheld from the judges. The content was not scrubbed. Some outputs contained an actions section that revealed a skill may have been consulted, and some judge verdicts noticed it. The next version of the harness judges outputs only, so that leak closes.

Two more bounds worth stating. Each task used one cold run and one loaded run, with one judge pass per pair, so the result is directional for this suite; it does not estimate run-to-run variance. And the eight tested skills were a selected subset of the 26 candidates, so the result should not be read as evidence that every candidate would have passed.

The released library is also not a straight copy of what was tested. The honest accounting: I consolidated the 26 repo-specific skills into 15 generalized skills (19 merged down to 9, including 2 that were largely absorbed into other merges; 6 carried over 1:1; 1 dropped as product-specific), plus 2 promoted from a separate personal library, for 17 total.

That has a consequence worth saying outright. 5 of the 17 released skills trace to A/B-measured sources. The measured deltas attach to the source skills as tested in their home repos, and the released rewrites carry the lineage, not a fresh measurement.
